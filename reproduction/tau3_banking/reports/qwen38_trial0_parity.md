### Exact commands

All commands run from `/home/tianhaowu/mono/tau3-banking` on the Linux evaluation host. The credential is loaded from `~/.rllm/config.json` and never appears in argv, logs, manifests, or this report.

#### Launch the guarded 97-task x1 evaluation

```bash
ALLOW_FULL_RUN=1 uv run --frozen --extra knowledge python \
  reproduction/tau3_banking/run.py full \
  --output-dir reproduction/tau3_banking/runs/qwen38_full_trial0_repeat \
  --execute --confirm-paid-api-calls --cost-ceiling-usd 150 \
  --allow-known-full-shell-drift
```

- `full` means the frozen 97-task trial-0 slice, not the public 97 x 4 aggregate.
- `--confirm-paid-api-calls` acknowledges model, user-simulator, and judge calls.
- `--cost-ceiling-usd 150` is a historical-cost acknowledgement, not a provider hard cap.
- `--allow-known-full-shell-drift` acknowledges the 11 classified Modal shell residuals.
- The authenticated preflight required at least the official $62.2505533 participant-chat cost before creating the run.
- Resume only the same immutable output manifest by appending `--resume`; never change config or copy scored outputs.

#### Run the strict offline comparison

```bash
uv run --offline --frozen --extra knowledge python \
  reproduction/tau3_banking/compare_results.py \
  reproduction/tau3_banking/runs/qwen38_full_trial0_repeat/results.json \
  --mode full \
  --output reproduction/tau3_banking/runs/qwen38_full_trial0_repeat/parity.json
```

Exit 1 is expected here because score, task vector, components, tools, and text do not match. Configuration, route, manifest, coverage, protocol, and grading-integrity fields must still pass.
